zhuzhu Copilot · 项目结构梳理

六、入口与运行链路

启动顺序（src/main.py）

  • 1. multiprocessing.freeze_support() — 兼容 PyInstaller 多进程
  • 2. 安装 _copilot_overlay_hook — 必须在导入主包之前，让 zhuzhu_Copilot.* 优先命中用户目录的源码覆盖层（打包版同样生效）
  • 3. 修正 sys.path（源码运行 / onedir / onefile 三态兼容），打包时把 stdout/stderr 重定向到 devnull 防崩溃弹窗
  • 4. 设置 QtWebEngine 环境变量（禁 GPU、禁沙箱，修复虚拟机/远程桌面白屏）与 QT_MEDIA_BACKEND=ffmpeg
  • 5. 在 QApplication 创建之前导入 QWebEngineView（Qt 硬性要求）
  • 6. 进入 ui/main_window.py 初始化主窗口与面板

运行方式

  • 源码运行：pip install -r src/requirements.txt → python src/main.py
  • 打包发布：.\build_release.ps1（体检→运行时/种子→PyInstaller 打包→签名→Inno Setup→产物自检）；-DryRun 只体检
  • 测试：pytest（pytest.ini 已设 pythonpath=src）

七、依赖清单

  • GUI：PyQt6>=6.7、PyQt6-WebEngine>=6.7、Pillow>=10.0、pywin32>=306
  • 办公文档：python-docx、openpyxl、python-pptx、pypdf（缺失时优雅降级）
  • 安全：yara-python>=4.5（缺失时 YARA 模块自动禁用，不影响其他防护）
  • 多媒体：pygame>=2.5（音乐播放与 TTS 回放，缺失静默降级）
  • 网络 / 账号：websockets>=12.0、httpx>=0.27、paramiko>=3.4（SSH 隧道代理回退）
  • 构建期：Cython>=3.0（可选，编译 .pyd）
依赖设计遵循「缺失即降级」原则：pypdf / yara-python / pygame 任一缺失都不会导致启动失败，对应功能静默降级并提示安装。
