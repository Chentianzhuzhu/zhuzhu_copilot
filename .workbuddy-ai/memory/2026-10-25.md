**2. 液体玻璃窗口 `src/zhuzhu_Copilot/ui/glass_window.py`（新核心模块）**
`GlassWindow`：无框 + 置顶 + 半透明 + 可拖拽（`startSystemMove`）可缩放（`startSystemResize`
+ 边缘光标），内容区 `setContent()`，多个窗口自动错位。
玻璃 = **GPU 逐像素算**：SDF 超椭圆法线 → 透镜折射（边缘厚中心薄）→ RGB 色散 →
菲涅尔×N·L 亮边 → Blinn-Phong 镜面高光 → 正弦扰动"液态角度"。
- 关键技术决策：**PyQt6 无 QOpenGLFunctions、Qt6 ShaderEffect 要预编译 .qsb（本仓库无 qsb
  工具链）→ 用 ctypes 直连 opengl32/wglGetProcAddress**，GLSL 1.20 + `ftransform()` +
  固定管线 GL_QUADS 提交（`_GLBinder` 懒加载函数指针，缺函数即抛）。
- 三个踩过的坑（已写进 README 8.8）：① 背景贴图必须比窗口**大 pad 圈**，否则边缘折射
  采样到窗口内部 → 发脏出色斑；② 单四边形要 `glDisable(GL_BLEND)`，开 SRC_ALPHA 混合
  会让透明 FBO 变预乘、读回二次乘算 → 亮部泛黄绿，且输出前必须 `clamp(col,0,1)`；
  ③ 抓屏前 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE=0x11)` 排除自己，否则背景
  拍到玻璃自己 → 反馈糊。
- `QScreen.grabWindow()` 在 PyQt6 返回 **QPixmap**，要 `.toImage()`（曾因此整个抓屏静默失败）。
- 磨砂放 CPU（缩小再放大），着色器只 3×3 精修；默认 60fps，隐藏即停表。
- 降级：`GLASS_MODE=painter` 强制 QPainter 半透明圆角面板；无 GL 环境自动降级；
  `GLASS_KEEP_CAPTURABLE=1` 允许被截屏（自测用）。`diagnostics()` 暴露 gpu/grab/surface_error。
