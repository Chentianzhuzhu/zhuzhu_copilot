### 本次改动
1. **登录握手 state（防 login CSRF / 重放）**
   - 新增 `app/core/login_state.py`：`issue_state` / `consume_state`（GETDEL 单次消费，TTL 600s）。
   - 新增 `POST /api/auth/state?platform=&version=`。
   - `LoginRequest` / `RegisterRequest` 增加 `state` 字段；login/register 前置校验。
   - 配置 `LOGIN_STATE_TTL_SECONDS=600`、`REQUIRE_LOGIN_STATE`（生产已设 **true**）。
2. **登录 URL 格式改造**（`src/zhuzhu_Copilot/core/auth_client.py`）
   - 形如 `{server}/static/login/index.html?platform=zhuzhu-copilot&state=<64hex>&version=<APP_VERSION>&callback_port=18765`。
   - 回调新增 `state` 原样带回，客户端用 `secrets.compare_digest` 校验，不一致拒绝 token。
   - 登录页 `static/login/index.html` 读取/回传 state。
3. **登录态健壮性**：`refresh_token` / `ensure_fresh_token` / `_token_expires_soon`（<6h 续期）、
   30 分钟定时巡检、`consume_points` 遇 401 自动续期重试一次、新增 `session_expired` /
   `login_rejected` 信号 + UI 弹窗引导重新登录；`set_server` 改为立即生效并重连 WS。
4. **安全加固**：`app/core/security.py` 加 `assert_jwt_secret_strength`（弱密钥拒绝启动）、
   `generate_jwt_secret`；`main.py` lifespan 启动自检；CORS 收敛为具体域名。
5. **Nginx 修复（关键）**：`/authapp/ws` 的 `proxy_pass` 缺 `$is_args$args`，
   `?token=` 被丢弃导致 WS 握手 400、客户端永远收不到实时推送。
   已改为 `proxy_pass http://127.0.0.1:8000/ws$is_args$args;` → 101 Switching Protocols。
