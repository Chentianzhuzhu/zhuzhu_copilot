## 卡片看板重构（UI/UX 美化，2026-10-24 凌晨）

用户反馈「三个卡片自适应没做好」→ 重写 `_CardBoard` / `_Card`（agent_panel.py）：

**布局**
- 列数随宽度自适应：卡片最小宽 250px，1~4 列（`MAX_COLS=4`），`resizeEvent` 检测列数变化后重排；
- 卡片高度按内容量算：`_Card.set_card_width(w)` 用 `QFontMetrics.boundingRect(QRect, flags, text)`
  量标题/描述/元信息在可用宽度下换行后的高度，逐卡 `setFixedHeight`；同一行取最高对齐；
- 每屏最多 10 张：`_relayout` 按「10 张所需行数」求和行高后 `setMaximumHeight` 封顶，超出滚动；
- 描述/元信息超长先截断（160/120 字）再换行，避免个别卡片撑爆。

**外观**
- 图标 30px 圆角底 + 首字母占位（有 icon 文件则缩放到 26px）；
- 标题 13px 粗、徽标胶囊（`ACCENT_HOVER` + 12% 底）、描述 12px、元信息 11px `TEXT_DIM`；
- 悬停描边 `ACCENT_HOVER` + 卡片底 `CARD`，选中描边 `ACCENT`；空列表显示「暂无内容」占位。

**踩坑**
1. `_clear_rows()` 里对行容器 `deleteLater()` 会**连带销毁子控件**（卡片仍在 `_cards` 里）→
   重排后访问就是已销毁的 C++ 对象。修法：清行前先把卡片 `setParent(None)` 摘出来。
2. `PANEL2` 不是模块级全局（对话框里用 `_base_color("CARD")`）→ 卡片样式改用 `CARD` 全局。
3. `QFontMetrics.boundingRect` 的 flags 参数在 PyQt6 传 `int(enum)` 可能报错，
   改用 `boundingRect(QRect(...), int(Qt.TextFlag.TextWordWrap.value), text)`。

**范围**：插件页 / Copilot 插件页 / 工作流页 / Agent 页子 Agent 列表四处全部换卡片；
交互按钮统一上移到卡片区上方，卡片区向下延伸滚动。`_Card` 补 `setData/data/setToolTip`
（子 Agent 用 UserRole 存名字）。

## Git 面板徽章修复 + 暂存面板点行勾选（2026-10-24 深夜）

**修复 1：origin/xxx 徽章丢失**（`agent_panel.py` GitLogWindow）
- 根因：`_on_data_ready` 提交视图按 `pushed`（分支头==上游头）门控 `upstream_hash`，
  新提交一落地 `pushed=False` → 连「上游指向的那条旧提交」上的徽章也整体消失。
- 修法：去掉 pushed 门控，`_fill_commits(rows, upstream_hash, upstream)` 恒传
  `upstream_hash`——徽章语义 = 上游指向的那条提交（该提交确实在远端，与本地
  是否领先无关）。参数改名 `pushed_hash/pushed_chip → upstream_hash/upstream_chip`。
- 分支视图（_fill_branches）保持原状：徽标仅 fully-pushed 时显示，tooltip 说明未推送。

**修复 2：暂存面板点击文件名直接勾选**（`_StageFilesDialog`）
- 新增 `_CheckNameList(QListWidget)`：mouseReleaseEvent 里命中复选框矩形的点击交还
  Qt 原生翻转，行内其余位置（文件名区域）手动翻转勾选。
- 复选框矩形用 `style().subElementRect(SE_ItemViewItemCheckIndicator)`（与绘制同源）+2px 容差。
- 双击不回弹：真实双击 = press,release,press,dblclick,release，两次 release 会翻转两次
  回到原点 → `_dbl_pending` 标志跳过第二次手动翻转（双击等效单击）。
  **标志必须一次性消费**（进 release 处理立即清零），否则双击复选框后残留会吞掉
  下一次正常单击（测试抓到过）。
- Qt 事实：原生委托在 Release **和 DblClick** 事件都会翻转复选框（双击复选框净翻转
  一次，原生行为未改）；QTest.mouseDClick 序列是 press+dblclick+release（无中间
  release），测真实双击必须用原始 QMouseEvent 序列逐事件发送。

**验证**：离屏真实构建 GitLogWindow（pushed False/True 两场景徽章分布断言）+
_StageFilesDialog 原始事件流（单击文件名翻转 / 复选框恰好一次 / 双击等效单击 /
无标志残留 / selected_paths 与勾选状态一致）全部通过。
