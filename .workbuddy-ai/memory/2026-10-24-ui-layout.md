# 2026-10-24 设置页布局修复 + 单列卡片（第二轮）

（原 2026-10-24.md 被占用写不进去，本条单独成文）

## 根因
用户截图：标题在上、说明跑到页面底部、中间大片空白、按钮消失。
`QStackedWidget` 的最小高度取**所有页最大值**（"通用与记忆"页 1136px），其余页被拉到同高，
QVBoxLayout 把多余空间分摊到控件之间 → 标题/说明被拉开、按钮被挤出视口。

## 修复（agent_panel.py）
1. `_wrap_page()`：每个设置页各自包一层 QScrollArea（首屏 + 两处懒加载），页高 = 自己内容高度。
2. 卡片区 / 大输入框后加 `lay.addStretch(1)`：多余空间留底部。
3. bash 白名单 / 系统提示词 的 QPlainTextEdit `setMaximumHeight(300)`。
4. 卡片改**单列通栏**（用户要求「一列一个排」）：[图标 32] [标题+描述+元信息] [徽标右对齐]，MAX_VISIBLE=10。
5. 卡片区高度 = min(内容高, 外层滚动区视口可用高)（`_fit_height` + showEvent/resizeEvent 触发）；
   resizeEvent 只在**宽度**变化时重排（否则 setFixedHeight 触发重排死循环）。

## 踩坑
1. 单列下卡片就是布局项，`_clear_rows()` 里的 deleteLater 会销毁卡片（重排后不显示）→ 只对非卡片控件 deleteLater。
2. `widgetResizable(True)` 会把容器压到视口大小且**不出滚动条** → 布局设 `SetMinimumSize` 约束。
3. 懒加载页首次显示 `self.y()==0`，可用高算偏大 → 3 次重试 + showEvent 再算。
4. `icon_text` 可能传整个名称，占位字母要 `[:1]`。

## 验证（offscreen + 系统 Python313 的 PyQt6）
17 页里 15 页页面高 == 视口高（无空隙）；通用与记忆(+555) / 音乐(+24) 保留页内滚动；
12 张卡时：卡片区 453px、内部滚动 704px、页面不滚 → 单层滚动条。
