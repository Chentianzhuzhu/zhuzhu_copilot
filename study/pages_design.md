# 在线记账本 MVP - 前端页面设计

## 一、设计概述

### 1.1 设计原则
- **简洁优先**：减少干扰元素，聚焦记账核心动作
- **快速录入**：记账流程不超过 3 步
- **视觉清晰**：收支用颜色区分（收入绿/支出红）
- **移动端优先**：适配手机屏幕，支持横竖屏

### 1.2 色彩方案
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #2563EB | 品牌蓝，用于按钮、标题 |
| 收入色 | #10B981 | 绿色，正向资金 |
| 支出色 | #EF4444 | 红色，负向资金 |
| 背景色 | #F8FAFC | 浅灰白，页面底色 |
| 文字色 | #1E293B | 深灰，主要文字 |
| 次要文字 | #64748B | 中灰，辅助信息 |
| 边框色 | #E2E8F0 | 浅灰，分割线 |

### 1.3 字体规范
- 字体家族：系统字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto）
- 主标题：20px 加粗
- 次标题：16px 加粗
- 正文：14px 常规
- 辅助：12px 次要

## 三、组件规范

### 3.1 按钮组件
| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 实心蓝底白字 | 主要操作（保存、确认） |
| 次按钮 | 白底蓝边蓝字 | 次要操作（取消、返回） |
| 文字按钮 | 纯文字无背景 | 链接、辅助操作 |
| 图标按钮 | 仅图标无文字 | 工具栏操作 |

### 3.2 输入组件
| 类型 | 样式 | 说明 |
|------|------|------|
| 文本输入 | 边框圆角 | 备注、搜索等 |
| 数字输入 | 键盘优化 | 金额、数量等 |
| 日期选择 | 弹出日历 | 日期、时间选择 |
| 选择器 | 底部弹窗 | 分类、类型选择 |

### 3.3 卡片组件
| 类型 | 样式 | 说明 |
|------|------|------|
| 数据卡片 | 圆角白色背景 | 展示统计数字 |
| 列表卡片 | 圆角白色背景 | 账单列表项 |
| 空状态 | 灰色图标+文字 | 无数据时展示 |

## 四、响应式适配

### 4.1 屏幕尺寸适配
- 最小宽度：320px（小屏手机）
- 推荐宽度：375px（主流手机）
- 最大宽度：414px（大屏手机）
- 平板适配：≥768px 双列布局

### 4.2 横竖屏适配
- 竖屏：标准单列布局
- 横屏：自适应宽度，保持核心操作区可见
