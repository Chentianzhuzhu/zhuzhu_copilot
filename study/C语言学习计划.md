# C 语言学习计划（零基础入门）

> 适合：完全没接触过编程 / 学过一点但没系统学过的同学
> 学习时长参考：每天 1 小时，约 8~10 周学完基础；想深入可延长到 3 个月

---

## 一、为什么学 C 语言？

- C 语言是**几乎所有编程语言的基石**：Java、C++、Python、Go 的底层很多都源于 C。
- 学了 C，你就能真正理解"内存"、"指针"、"程序是怎么跑起来的"这些概念。
- 嵌入式、操作系统、驱动、游戏引擎、单片机等方向都离不开 C。
- 学完 C 再学其他语言，会轻松很多。

---

## 二、开发环境搭建（第一步，先做好）

你的电脑目前没有安装 C 编译器，需要先装一个。推荐二选一：

| 方案 | 适合人群 | 说明 |
|------|---------|------|
| **VS Code + MinGW-w64** | 主流选择，轻量、可扩展 | 写代码体验好，需要自己配编译命令 |
| **Dev-C++** | 纯新手、图省事 | 开箱即用，一键编译运行，界面简单 |

> 也可用在线编译器（如 onlinegdb.com）先练起来，但**强烈建议装本地环境**，因为本地才有真实的"编译 → 报错 → 修复"过程，这正是学 C 的核心训练。

**第一步 Hello World：**

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

保存为 `hello.c`，编译运行：`gcc hello.c -o hello`，然后运行 `./hello`。

## 三、学习路径（4 个阶段）

### 阶段 1：基础语法（第 1~3 周）—— 能写出跑起来的程序
目标：掌握变量、数据类型、输入输出、运算符、条件判断、循环。

### 阶段 2：函数与数组（第 4~5 周）—— 学会拆分问题
目标：会写函数、传参、返回；会用数组存一批数据。

### 阶段 3：指针与字符串（第 6~7 周）—— C 的灵魂，也是难点
目标：理解内存地址、指针、指针与数组的关系、字符串处理。
> 这一阶段是分水岭，很多人在这里放弃，坚持住就赢了一半。

### 阶段 4：结构体、文件与综合实战（第 8~10 周）—— 能做小项目
目标：会用结构体组织数据、读写文件，能独立完成一个管理类小项目。

## 四、核心知识点清单（按重要性排序）

### ★★★ 必须掌握（基础中的基础）
1. 变量与数据类型：`int` / `float` / `double` / `char`，`sizeof` 求字节数
2. `printf` / `scanf` 格式化输入输出（`%d` `%f` `%c` `%s`）
3. 运算符：算术 `+ - * / %`、关系 `== != > <`、逻辑 `&& || !`、赋值 `= += -=`
4. `if / else`、`switch` 条件分支
5. `for` / `while` / `do-while` 循环，`break` / `continue`
6. 函数的定义、调用、参数、返回值
7. 一维数组的定义、遍历、求最大最小值、冒泡排序

### ★★ 重要（进阶核心）
8. 二维数组
9. 指针基础：`&` 取地址、`*` 解引用
10. 指针与数组的关系（数组名即首地址）
11. 字符串与字符数组：`char s[]`、`strlen` `strcpy` `strcmp` `strcat`
12. 指针作为函数参数（实现"修改外部变量"）
13. 结构体 `struct` 的定义与使用
14. 文件操作：`fopen` / `fclose` / `fprintf` / `fscanf`

### ★ 了解即可（知道概念，用到再深究）
15. 动态内存分配：`malloc` / `free`
16. 指针数组、数组指针、函数指针
17. 链表、递归、位运算
18. 预处理指令：`#define` / `#include` / 条件编译

## 五、练习方案（每知识点 2~3 题 + 思路）

> 学编程 70% 靠敲代码，看十遍不如敲一遍。每题先自己写，卡住 15 分钟再看答案。

### 第 1 周 练习题（变量 / 输入输出 / 运算符）
1. 输入两个整数，输出它们的和、差、积、商、余数。
2. 输入一个三位数，逆序输出（如 123 → 321）。
3. 输入摄氏温度，输出华氏温度（公式 F = C × 9/5 + 32）。

### 第 2 周 练习题（条件分支）
1. 输入一个年份，判断是否为闰年（能被 4 整除且不能被 100 整除，或能被 400 整除）。
2. 输入三个数，输出最大值。
3. 用 switch 写一个"星期几"程序：输入 1~7 输出对应星期。

### 第 3 周 练习题（循环）
1. 打印 1~100 之间所有能被 3 整除的数。
2. 计算 1 + 1/2 + 1/3 + ... + 1/n（n 由用户输入）。
3. 打印九九乘法表。
4. （进阶）打印菱形星号图案。

### 第 4 周 练习题（函数）
1. 写一个函数判断一个数是否为素数，主函数调用它输出 1~100 内所有素数。
2. 写一个函数计算阶乘 n!，分别用循环和递归两种方式。
3. 写一个函数交换两个变量的值（**必须用指针才能实现**，为阶段 3 铺垫）。

### 第 5 周 练习题（数组）
1. 输入 10 个数存入数组，输出最大值、最小值、平均值。
2. 冒泡排序：输入 10 个数，升序输出。
3. 数组逆序存放。

### 第 6~7 周 练习题（指针 / 字符串）
1. 用指针遍历数组并输出每个元素。
2. 用指针作为参数，实现交换两个数、求数组元素和。
3. 自己实现 `strlen`（统计字符串长度，不许用库函数）。
4. 输入一个字符串，统计其中数字、字母、其他字符各有多少个。

### 第 8 周 练习题（结构体）
1. 定义学生结构体（学号、姓名、成绩），输入 5 个学生，输出最高分者。
2. 结构体数组按成绩排序。

### 第 9 周 练习题（文件）
1. 把 1~100 的平方写入文件 `square.txt`，再读出来打印。
2. 从文件读入一组学生成绩，计算平均分。

### 第 10 周 综合实战（选一个做）
1. **学生成绩管理系统**：增删改查 + 存文件（最经典，强烈推荐）
2. 简易计算器：支持 + - * / 和括号
3. 猜数字游戏 / 贪吃蛇（控制台版）

## 六、学习建议与避坑指南

### 学习方法
- **每日固定练习**：哪怕只写 20 分钟，也要保证每天动手，连续性比单次时长重要。
- **先抄后写**：一开始可以抄别人的代码，但抄完必须自己默写一遍、改一改，确保真懂。
- **错误是最好的老师**：编译报错很正常，认真读报错信息，这是最重要的学习机会。
- **画图理解内存**：学指针时，在纸上画内存格子（每个变量一个格子、箭头指向地址），比空想强十倍。

### 常见坑（提前避开）
1. **scanf 忘写 `&`**：`scanf("%d", &n)`，漏了 `&` 程序会崩或乱。
2. **分号漏写**：每个语句结尾的 `;`。
3. **数组越界**：`int a[5]` 只能用 `a[0]~a[4]`，`a[5]` 越界，C 不报错但会出诡异 bug。
4. **字符串忘加 `\0`**：字符数组结尾要有结束符。
5. **`==` 和 `=` 搞混**：判断相等用 `==`，赋值用 `=`。
6. **函数里改了参数但外部没变**：C 是值传递，想改外部变量必须传指针。

| LeetCode / 洛谷 | 刷题 | 学完基础后可刷简单题巩固 |

### 学习节奏建议
- 每天 1 小时：工作日学语法 + 做题，周末做综合小项目。
- 卡住的地方（尤其指针）**不要跳过**，跳过后面全崩。卡几天正常，熬过去就通了。
- 每学完一个阶段，写一个能"用起来"的小程序巩固（哪怕是个计算器）。
