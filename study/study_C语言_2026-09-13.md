## 2. 诊断自测（6 题，先做后看答案）

**规则**：闭卷、不上机、20 分钟内完成；允许"不会"，如实标记。评分只看"关键要点是否说到"，不要求语法满分。本章题目在第 10 周 Day5 作为结业自测重做一遍，对比前后答案。

### 题 1（基础语法：类型与运算）

读代码写输出：

```c
int a = 7, b = 2;
printf("%d %.1f %d\n", a / b, (float)a / b, a % b);

int i = 3;
printf("%d %d %d\n", i++, ++i, i);
```

**答案要点**：第一行输出 `3 3.5 1`——整数除法截断、强制类型转换后得浮点、`%` 取余。第二行属**未定义行为**：同一表达式中对 i 既读又多次修改，求值顺序未定义，不同编译器输出可能不同；能指出"这是 UB、应拆开写"记满分。

### 题 2（分支与循环）

写一段代码：统计 1~100 中能同时被 3 和 5 整除的数的个数并打印。

**答案要点**：循环 `for (n = 1; n <= 100; n++)`；条件 `n % 15 == 0`（或 `n % 3 == 0 && n % 5 == 0`）；计数器初值 0，循环结束后 printf。能说出"循环三要素（初值、条件、步进）+ 累加器模板"即为掌握。

### 题 3（函数与数组）

(1) 写出函数 `int find_max(int a[], int n)` 求数组最大值；(2) 解释为什么在函数内部用 `sizeof(a) / sizeof(a[0])` 求不出元素个数。

**答案要点**：(1) 遍历比较；注意 n ≤ 0 的边界（约定返回一个特殊值或 0）。(2) 数组作参数时退化为指向首元素的指针，sizeof 得到的是指针大小（4 或 8 字节），不是整个数组的大小；长度必须作为参数传入。

### 题 4（指针）

设有 `int a[5]; int *p = a;`，解释 `p+1`、`*(p+1)`、`&a[1]`、`a+1` 四者关系；再说明 `a` 与 `&a` 的区别。

**答案要点**：`p+1`、`a+1`、`&a[1]` 的值相同（都指向 a[1]，按 int 步长前进 4 字节）；`*(p+1)` 就是 a[1]，也等于 `*(a+1)`。`a` 是首元素地址，类型 int*；`&a` 是"整个数组的地址"，类型 int(*)[5]，`&a+1` 会跨过 20 字节。

### 题 5（字符串）

比较 `char s[] = "hello";` 与 `char *t = "hello";`；说明求长度、复制、比较内容分别用什么函数；为什么不能用 `==` 比较两个字符串内容。

**答案要点**：s 是可修改的字符数组（占 6 字节，含结尾 `'\0'`）；t 指向只读的字符串常量，写 t[0] 属未定义行为。函数：strlen / strcpy（或更安全的 strncpy）/ strcmp。`==` 比较的是地址（首地址是否相同），不是内容。

### 题 6（结构体与文件）

定义学生结构体（学号、姓名、三门成绩、平均分），并写出"从 students.txt 读入一条记录"的关键代码；说明 fopen 返回 NULL 时该怎么办。

**答案要点**：`struct Student { int id; char name[20]; float score[3]; float avg; };`；`FILE *fp = fopen("students.txt", "r");` 后**必须判空**（`if (fp == NULL) { 打印错误信息并安全退出; }`），再 fscanf/fgets 解析，用完 fclose。漏判 fopen 即扣分。

## 6. 知识卡片（22 张，按"正面提问 / 背面要点"使用）

> 用法：抄成纸卡或录入记忆类 App；正面只写问题，背面先自己答再看要点。随机抽答，答不出的当天重复一次（间隔复习）。

| 编号 | 正面（问题） | 背面（答案要点） |
|---|---|---|
| 1 | & 和 * 分别是什么？ | & 是取地址运算符（得到变量地址）；* 是解引用运算符（访问指针所指地址上的值）。注意：声明 `int *p;` 里的 * 只是"这是指针"的类型标记，不是解引用。 |
| 2 | `int a = 5; int *p = &a; *p = 8;` 之后 a 是多少？为什么？ | a 变成 8。*p 与 a 是同一块内存的两种写法，改 *p 就是改 a。 |
| 3 | 数组名 a 在表达式里代表什么？什么时候例外？ | 代表首元素地址（退化为 int*）。例外：sizeof(a) 与 &a 时——前者得整个数组字节数，后者得"数组指针"类型。 |
| 4 | p+1 与 a+1 的步长是多少？由什么决定？ | 都前进"一个元素"的字节数（int 数组为 4 字节）。步长由指针所指类型的大小决定，与指针自身大小无关。 |
| 5 | a[i] 与 *(a+i) 是什么关系？ | 完全等价。a[i] 会被编译器翻译成 *(a+i)，所以 i[a] 也能通过编译（但不要这么写）。 |
| 6 | `a` 与 `&a` 有什么区别？ | 值相同但类型不同：a 是 int*（首元素地址），&a 是 int(*)[N]（整个数组地址）。a+1 走 4 字节，&a+1 走 N×4 字节。 |
| 7 | 为什么在函数里 sizeof(arr) 得不到数组长度？ | 数组作参数时退化为指针，sizeof(arr) 得到的是指针大小（4 或 8 字节）。长度必须作为单独参数传入。 |
| 8 | C 是值传递，为什么函数内能改数组元素？ | 传的是"首地址的副本"，副本与原指针指向同一块内存，所以能改内存内容；但修改指针本身（让它指向别处）不影响外部。 |
| 9 | 写一个交换两个变量的函数，并解释为什么必须传指针。 | `void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }` 调用 `swap(&x, &y);`。值传递只复制值，函数内改形参不影响外部；传地址后通过 * 解引用才能改到外部变量。 |
| 10 | C 字符串在内存里是什么？`char s[] = "hi"` 与 `char *p = "hi"` 有何差异？ | 是以 '\0' 结尾的 char 序列。s 是可改写的数组（内容在栈上，可改）；p 指向只读字符串常量，改 p[0] 属未定义行为。 |
| 11 | 对 `char s[] = "abc";`，strlen(s) 与 sizeof(s) 各是多少？ | strlen 是 3（不含 '\0'，运行时计算）；sizeof 是 4（含 '\0'，编译期已知）。 |
| 12 | 为什么不能用 == 比较两个字符串？ | == 比较的是两个地址是否相同，不是内容。比较内容用 strcmp，返回 0 表示相等。 |
| 13 | 手写 my_strlen。 | `size_t my_strlen(const char *s) { size_t n = 0; while (*s) { n++; s++; } return n; }` 靠 '\0' 结束，注意 const 与 size_t。 |
| 14 | 用 strcpy 要注意什么？自己实现时怎么写？ | 目标缓冲区必须足够大（strcpy 不检查容量，会越界）；实现时循环复制到 '\0'：`while ((*d++ = *s++));` 生产代码优先 strncpy 或 snprintf。 |
| 15 | 什么是野指针？如何预防？ | 指向不确定/已释放内存的指针。预防：定义即初始化（NULL 或有效地址）；使用前判空；free 后立即置 NULL；不返回局部变量地址。 |
| 16 | malloc/free 有哪些常见错误？ | 忘 free（泄漏）；重复 free；用已 free 的指针（悬空）；越界写；不判 malloc 返回 NULL。规则：谁申请谁释放，成对书写。 |
| 17 | 什么时候用点号，什么时候用箭头？ | 结构体变量用 `stu.score`；结构体指针用 `p->score`（等价于 `(*p).score`）。 |
| 18 | 结构体能整体赋值吗？能直接用 == 比较吗？ | 能整体赋值（成员逐个复制）；不能直接用 == 比较，需逐成员比较（或 memcmp，但注意填充字节可能干扰）。 |
| 19 | fopen 返回什么？为什么必须检查？ | 返回 FILE*，失败返回 NULL。不检查就继续 fscanf/fprintf 会崩溃或产生未定义行为；标准写法：打开后立刻 if 判空并给出错误提示。 |
| 20 | 文件模式 "r" 与 "rb"、"w" 与 "a" 有何区别？ | "rb" 是二进制模式（Windows 下不做换行转换）；"w" 清空原内容重写（文件不存在则创建）；"a" 追加到末尾。读不存在文件用 "r" 会失败返回 NULL。 |
| 21 | `const char *p` 与 `char * const p` 有何区别？ | 前者：不能通过 p 改内容（*p 只读），p 本身可指向别处；后者：p 本身不能改指向，但能改指向的内容。读法：const 修饰它右边最近的东西。 |
| 22 | 为什么不能返回局部变量的地址？ | 局部变量在栈上，函数返回后其内存失效，返回的地址成为悬空指针（未定义行为）。替代：用 static、malloc，或由调用方传入缓冲区。 |

> 每个模块学完先自评"通过标准"，再做检验题；错哪题就按"答错回退"复习对应前置概念，24 小时后再测一次。

### 7.1 M1 基础语法

**通过标准（全部满足才算过）**
- [ ] 能独立搭好环境，从写代码到编译运行不查教程；
- [ ] -Wall -Wextra 编译自己的程序零警告；
- [ ] 能说清整数除法、取余、类型转换三者的行为；
- [ ] 能用 for/while/do-while 各写一个计数或累加程序，并说清适用场景；
- [ ] 能解释 = 与 ==、break 与 continue 的差别。

**检验题**

Q1. 写出下列循环的输出：

```c
for (int i = 5; i; i--) printf("%d", i);
```

**答案**：`54321`。**解析**：循环条件不是"i > 0"，而是"i 非零"；C 中 0 为假、非 0 为真，i 从 5 递减到 1 时都为真，到 0 结束。

Q2. 写程序：不断读入正整数（读到 0 结束），统计奇数个数与总和。

**答案要点**：循环 + `if (n % 2 == 1) cnt++;` + `sum += n;`；注意 0 只作为结束标志不计入；对输入为负数的处理可自行约定（如跳过或提示）。**解析**：这是"循环三要素 + 条件统计 + 累加器"的综合，是后续所有程序的骨架。

Q3. `printf("%d", 7 / 2)` 与 `printf("%.1f", 7 / 2.0)` 分别输出什么？为什么？

**答案**：`3` 与 `3.5`。**解析**：两个整数相除结果是整数（截断）；只要有一个操作数是浮点，就按浮点运算。

Q4. 判断：`if (x = 3) { ... }` 会发生什么？

**答案**：这是赋值不是比较，x 被赋值为 3，表达式值为 3（真），分支**恒被执行**。**解析**：经典笔误，应写 `x == 3`；把编译警告当回事（很多编译器会提示可疑赋值）。

**答错回退**：错 Q1 → 重学"表达式的真假值 + 循环条件"；错 Q2 → 重学"循环三要素 + 累加器模板"（并重做 W2 Day5 练习）；错 Q3 → 重学"整数与浮点、类型转换规则"；错 Q4 → 重学"运算符与优先级"并重做 W1 Day7 的"故意改错"实验。

### 7.2 M2 函数与数组

**通过标准**
- [ ] 能把一个 100 行程序拆成 3~5 个职责单一的函数；
- [ ] 能解释值传递与"数组作参数能改内容"的原理；
- [ ] 能独立写出选择排序或冒泡排序（含边界处理）；
- [ ] 能写二分查找并说明前提（有序）；
- [ ] 能不查资料说出"数组作参数必须传长度"的原因。

**检验题**

Q1. 下面函数打印的为什么不是数组元素个数？

```c
void f(int a[]) { printf("%zu\n", sizeof(a) / sizeof(a[0])); }
```

**答案**：因为 a 已退化为指针，sizeof(a) 是指针大小，除以 int 大小得到 2（64 位下）或无意义值。**解析**：正确做法是 `void f(int a[], int n)`，由调用方传长度。

Q2. 写 `int find_max(int a[], int n)`，并处理 n ≤ 0 的边界。

**答案要点**：先判 `if (n <= 0) return 0;`（或约定返回特殊值并注释），再 `int m = a[0]; for (i = 1; i < n; i++) if (a[i] > m) m = a[i];`。**解析**：边界处理是"函数是否健壮"的分水岭。

Q3. 写出 swap 函数并说明为什么必须传指针；如果传的是数组，swap 两个元素还需要指针吗？

**答案要点**：`void swap(int *a, int *b)` + 调用 `swap(&x, &y)`；因为值传递改不了外部变量，必须传地址。数组元素可直接 `swap(&a[i], &a[j])`——数组本身已能通过地址改内容，但交换的是两个具体元素，仍需它们的地址。

Q4. 一轮冒泡（升序）后数组 `{5, 3, 8, 1}` 变成什么？

**答案**：`{3, 5, 1, 8}`。**解析**：从头比较相邻两两交换，8 像气泡一样"浮"到末尾；一轮不保证全序，需要多轮。

Q5. 二分查找在什么情况下必须放弃？给出两个边界测试用例。

**答案要点**：数组无序时必须先排序或改用线性查找；测试用例：查找首元素、查找不存在元素（确认不会死循环）。**解析**：`while (low <= high)` 的等号、`mid` 的更新是常见死循环来源。

**答错回退**：错 Q1 → 回 M2"数组作参数与退化"，并重做 W3 Day2 值传递实验；错 Q2 → 重学"函数返回值与边界条件"；错 Q3 → 回到 M2"值传递"并预习 M3"地址与指针"；错 Q4/Q5 → 重做 W4 Day3~Day5 三个练习。

### 7.3 M3 指针与字符串（重点模块）

**通过标准**
- [ ] 能在纸上画"变量-地址-内容"内存图解释任意一段指针代码；
- [ ] 能说清 a、&a、a+1、*(a+1)、p+1 的类型与步长；
- [ ] 能独立写 swap 与"一次返回最值两个结果"的函数；
- [ ] 能手写 my_strlen 与 my_strcpy（限时、不查资料）；
- [ ] 能说出空指针、野指针、越界写、改字符串常量四类崩溃的成因。

**检验题**

Q1. 写出输出：

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a + 2;
printf("%d %d\n", *(p - 1), p[2]);
```

**答案**：`2 5`。**解析**：p 指向 a[2]；p-1 回到 a[1] 得 2；p[2] 即 *(p+2)，指向 a[4] 得 5。指针下标与数组下标规则一致。

Q2. 指出下面代码的危险之处并给出正确写法：

```c
char *s = "abc";
s[0] = 'A';
```

**答案**：s 指向字符串常量（只读区），写入属未定义行为（可能崩溃、可能无效）。正确写法：`char s[] = "abc"; s[0] = 'A';`（数组在可写内存里）。

Q3. 手写 my_strcpy，返回值与标准库一致。

**答案要点**：

```c
char *my_strcpy(char *dst, const char *src) {
    char *ret = dst;
    while ((*dst++ = *src++)) { }
    return ret;
}
```

**解析**：赋值表达式的值就是被复制的字符，复制到 '\0' 时值为 0，循环结束；返回原 dst 以支持链式调用。

Q4. 用指针实现：把数组前 n 个元素原地逆序。

**答案要点**：`int *l = a, *r = a + n - 1; while (l < r) { int t = *l; *l++ = *r; *r-- = t; }`。**解析**：首尾双指针向中间靠拢，注意 n 为 0/1 时循环体不执行（自然安全）。

Q5. `int *p; *p = 5;` 有什么问题？怎么修？

**答案**：p 未初始化（野指针），向随机地址写入可能崩溃或静默破坏数据。修法：先让 p 指向有效内存，例如 `int x; int *p = &x; *p = 5;` 或先 malloc。

**答错回退**：错 Q1 → 回"指针算术 + 数组下标本质（a[i] 即 *(a+i)）"，重做 W5 Day3；错 Q2 → 回"内存分区与字符串常量"，重做 W6 Day2；错 Q3/Q4 → 回"循环 + 指针遍历模板"，重做 W6 Day4；错 Q5 → 回"指针初始化与野指针"，重做 W5 Day5。

### 7.4 M4 结构体与文件

**通过标准**
- [ ] 能定义含数组/嵌套成员的结构体，求 sizeof 并解释为什么可能大于成员之和；
- [ ] 能用结构体数组完成按成员排序；
- [ ] 能完成"读文件→处理→写文件"闭环，且每次 fopen 都有判空；
- [ ] 能说清 malloc/free 配对、内存泄漏与悬空指针；
- [ ] 能区分文本/二进制模式，知道 Windows 下换行的差异。

**检验题**

Q1. 定义学生结构体并按平均分降序排序（写出关键比较与交换代码）。

**答案要点**：结构体含 id/name/score[3]/avg；排序时比较 `s[j].avg < s[j+1].avg` 再交换**整个结构体**（`struct Student t = s[j]; s[j] = s[j+1]; s[j+1] = t;`）。**解析**：结构体可整体赋值，这让排序代码与 int 数组版几乎一样。

Q2. 为什么 `sizeof(struct S)` 可能大于各成员大小之和？

**答案**：内存对齐产生填充字节（padding），例如 int 后面接 char 常留 3 字节空隙。**解析**：知道有这回事即可；写文件建议逐成员 fprintf，不要直接把整个结构体二进制写盘再跨平台读。

Q3. 写代码：把结构体数组写入文件，再读回并校验记录条数。

**答案要点**：写用 `fprintf(fp, "%d %s %f\n", ...)` 一行一条；读用 `while (fscanf(fp, "%d %s %f", ...) == 3) count++;` 或 fgets+解析；关闭文件后再重新 fopen 读取校验。**解析**：用"fscanf 返回值等于期待项数"判断是否读成功，是稳健写法。

Q4. malloc 之后忘记 free 会怎样？如何自查？

**答案**：内存泄漏——程序运行期间占用只增不减（长跑程序可能耗尽内存）；自查：搜索 malloc 附近是否有对应 free、用内存检查工具（如 AddressSanitizer、Valgrind 类工具）、养成"申请即想好谁来释放"的习惯。

Q5. fopen 返回 NULL 时继续 fscanf 会怎样？如何修复？

**答案**：FILE* 为空指针，继续使用是未定义行为（通常直接崩溃）。修复：打开后立即判空并给出可读错误信息（如"无法打开 students.txt"），再决定返回或退出。

**答错回退**：错 Q1 → 回"结构体数组 + 排序"（M2 排序 + M4 结构体叠加）；错 Q2 → 回"类型与内存布局"（M1 sizeof + M4 对齐）；错 Q3/Q5 → 回"文件四步（打开-判空-读写-关闭）"并重做 W8 Day3；错 Q4 → 回"指针生命周期与动态内存"重做 W8 Day5。

## 8. 常见误区清单（进门版 6 条复盘 + 15 条深挖）

### 8.1 入门版 6 条的"深挖版"

| 原误区 | 只知其一 | 还要知其二 |
|---|---|---|
| scanf 忘 & | 除数组名字外都要取地址 | %s 传字符数组名本来就不用 &；%c 前加空格可吃掉残留的换行/空白 |
| 分号漏写 | 语句结尾要加 ; | do-while 的 while(...) 后面必须加；struct/enum/函数定义的大括号后**不能**加 |
| 数组越界 | 下标不能超过长度-1 | 越界不一定立刻崩溃（可能静默改坏别的变量）；循环条件里的 <= 是重灾区 |
| 字符串忘 \0 | 字符数组末尾要留结束符 | 手写复制循环必须自己补 '\0'；容量要按"字符数+1"申请 |
| == 与 = 搞混 | 比较用 == | if/while 条件里写赋值往往"恒真"，编译器可能只给警告不报错 |
| 值传递改不了外部变量 | 想改外部就要传地址 | 数组与指针是例外（传的是地址副本，能改指向的内容）；结构体传参是整体复制，改成员不影响外部 |

### 8.2 深挖补充 15 条

| 编号 | 现象 | 原因/后果 | 正确做法 |
|---|---|---|---|
| 1 | scanf("%d") 后接 scanf("%c") 读到"空字符" | 数字后面的换行还留在缓冲区，被 %c 吃掉 | 用 " %c"（前导空格）跳过空白，或先消费整行 |
| 2 | 输错内容后程序死循环 | 忽略 scanf 返回值；非法输入一直读不进去 | 检查返回值，错误时清空缓冲区或整行读入再解析 |
| 3 | sizeof 与 strlen 混用 | 一个算内存、一个算长度（见卡片 11） | 记住：sizeof 编译期、含 '\0'；strlen 运行时、不含 '\0' |
| 4 | 想用 `a = b` 复制数组 | 数组名是地址常量，不能作左值，编译报错 | 用 strcpy（字符数组）或 memcpy/循环（其他数组） |
| 5 | 用已 free 的指针 | 悬空指针：内存可能已被复用，读写结果不可预测 | free 后立即置 NULL；绝不重复 free |
| 6 | strcpy 目标空间不够 | 越界写，可能覆盖相邻变量或崩溃 | 先确认容量；优先 strncpy/snprintf 并手动补 '\0' |
| 7 | 用 == 比较浮点数 | 浮点存在精度误差，如 0.1+0.2 不等于 0.3 | 比较差值：`fabs(a-b) < 1e-6` |
| 8 | `for (unsigned i = n; i >= 0; i--)` 死循环 | 无符号数减到 0 再减 1 变成极大值，条件恒真 | 用有符号 int，或改用 `i-- > 0` 的写法 |
| 9 | 百分比算出来全是 0 | 整数除法先截断，再赋值给浮点已晚 | 先转浮点或先乘后除：`(float)cnt / total * 100` |
| 10 | switch 忘 break / 用错类型 | 会"穿透"执行下一个 case；case 不能跟浮点或字符串 | 每个分支加 break（除非故意穿透）；含 default |
| 11 | 宏没加括号 | `#define SQ(x) x*x` 遇到 SQ(1+2) 展开错误 | 参数与整体都加括号；能用函数就别用宏 |
| 12 | 函数返回局部数组/局部变量地址 | 栈内存已失效，拿到悬空指针 | 用 static 数组、malloc，或由调用方传缓冲区 |
| 13 | 用 gets 读字符串 / fgets 后多出空行 | gets 已被标准移除且极易溢出；fgets 会保留换行 | 只用 fgets，读后按需去掉末尾 '\n' |
| 14 | 程序写文件"没生效" | 忘 fclose（缓冲未落盘）或忘判 fopen 失败 | 打开即判空，用完必 fclose，退出前再检查一次 |
| 15 | 调试时"改一点试一点"，从不读完整报错 | 第一个错误常引发一片连锁错误，逐个猜很慢 | 先修**第一个**错误；开 -Wall -Wextra -g；必要时用断点看变量与调用栈 |

> 补充两条"行为习惯"误区：① 只收藏资料不动手（本计划要求每天有可运行代码）；② 遇到段错误就重装环境（先看代码是否空指针/越界，段错误八成是自己写出来的）。
