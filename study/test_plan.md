## 二、核心测试用例

### 2.1 记账流程测试

#### TC-001: 快速记账（Happy Path）
| 项目 | 内容 |
|------|------|
| 用例ID | TC-001 |
| 场景 | 用户快速录入一笔支出 |
| 前置条件 | 已登录，默认账本存在 |
| 测试步骤 | 1. 点击首页「+」按钮<br>2. 输入金额 ¥50<br>3. 选择「支出」类型<br>4. 选择分类「餐饮」<br>5. 点击「保存」 |
| 预期结果 | 1. 返回账单列表页<br>2. 列表顶部显示刚添加的账单<br>3. 金额显示为红色「-¥50.00」<br>4. 首页本月支出数字更新 |
| 优先级 | P0 |

#### TC-002: 收入记账
| 项目 | 内容 |
|------|------|
| 用例ID | TC-002 |
| 场景 | 用户记录一笔工资收入 |
| 前置条件 | 已登录 |
| 测试步骤 | 1. 点击记账按钮<br>2. 输入金额 ¥5000<br>3. 切换为「收入」类型<br>4. 选择分类「工资」<br>5. 点击「保存」 |
| 预期结果 | 1. 成功保存收入记录<br>2. 金额显示为绿色「+¥5000.00」 |
| 优先级 | P0 |

#### TC-003: 异常输入处理
| 项目 | 内容 |
|------|------|
| 用例ID | TC-003 |
| 场景 | 用户输入非法金额 |
| 测试步骤 | 1. 在金额输入框输入负数「-100」<br>2. 输入字母「abc」<br>3. 输入超过精度「10.999」<br>4. 不输入金额直接点击保存 |
| 预期结果 | 1. 负数：提示「金额不能为负数」<br>2. 字母：键盘自动过滤或提示「请输入数字」<br>3. 超出精度：自动四舍五入至两位小数<br>4. 空值：按钮置灰或提示「请填写金额」 |
| 优先级 | P0 |

#### TC-004: 备注功能
| 项目 | 内容 |
|------|------|
| 用例ID | TC-004 |
| 场景 | 用户填写备注信息 |
| 测试步骤 | 1. 打开记账表单<br>2. 在备注框输入「午餐加了一瓶饮料」<br>3. 完成其他必填项并保存 |
| 预期结果 | 1. 账单列表中显示该备注<br>2. 备注最多支持200字，超出提示 |
| 优先级 | P0 |
