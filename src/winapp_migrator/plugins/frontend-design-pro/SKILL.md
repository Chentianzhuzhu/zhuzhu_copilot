## 触发条件
- 用户请求添加动画效果（如滚动动画、悬停效果、过渡动画等）
- 用户要求美化H5页面或Vue3组件
- 用户需要CSS特效或JavaScript动效实现
- 用户要求优化前端视觉体验

## 执行流程
1. 分析用户需求，确定目标技术栈（HTML/CSS/JS/Vue3）
2. 选择合适的动画方案：
   - CSS动画：@keyframes、transition、transform
   - JavaScript动画：requestAnimationFrame、GSAP、Anime.js
   - Vue3动画：<transition>、<transition-group>、VueUse
3. 生成高质量代码示例
4. 提供详细注释和使用说明
5. 确保动画性能优化（使用transform/opacity，避免重排）

## 输出规范
- 代码完整可运行
- 包含必要的HTML结构
- CSS动画使用现代特性
- JavaScript代码兼容主流浏览器
- Vue3示例使用Composition API
