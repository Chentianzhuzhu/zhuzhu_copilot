# code-map · 工作区代码地图

扫描任意目录，一眼看清：**有多少文件、多少代码、重心在哪个子目录、哪些文件最重**。
综合性 Copilot 插件的标准范本——新建源码模块 + 插入接线 + 应用扩展四项齐全 +
Agent 技能 + 自定义图标。

## 一、它做了什么

| # | op | 目标 | 作用 |
| --- | --- | --- | --- |
| 1 | `create_file` | `core/code_map.py` | 扫描内核：目录遍历、行数统计、分布聚合、结果缓存、文本报告 |
| 2 | `insert_after` | `core/agent_tools.py` | 在 `TOOLS = [` 后登记 `code_map` 工具（参数 path/depth/top） |
| 3 | `insert_after` | `core/agent_tools.py` | 在 `revert_copilot_plugin` 分支后接线工具分发 |

`copilot.json` 注册四项应用扩展：

| 类型 | 内容 |
| --- | --- |
| `pages` | 「代码地图」看板页：指标卡 + 类型分布 + 最大文件 + 子目录条形图 |
| `services` | 启动预热 + 每 10 分钟刷新缓存（配置见 `config.json`） |
| `tray` | 「代码地图报告」托盘菜单项 |
| `shortcuts` | `Ctrl+Alt+W` 弹报告 |

外加 `agent/SKILL.md`：导入时登记为技能 `/code-map`，教 AI 什么时候该用它。

## 二、图标

`icon.png`（256×256，圆角深蓝底 + 浅蓝文件夹 + 三根柱状图），由脚本纯标准库光栅化生成
（4× 超采样抗锯齿），不依赖任何图形库。`plugin.json` 里写 `"icon": "icon.png"`（只写文件名），
设置 → Copilot 插件页的卡片头像就是它。

## 三（附）、玻璃窗口与热插拔

看板页用 `"window": "glass"` 托管在**独立无框液体玻璃窗口**里：应用启动即常驻浮现，
可拖拽标题区移动、贴边缩放，背景是真实桌面，玻璃折射/反射/边缘高光由 GPU 逐像素算
（见根 README 第八章 8.8）。只想在浮层里看就删掉 `copilot.json` 里该页面的
`"window": "glass"`，改回默认页签即可。

**停用插件会立刻关掉这个窗口**（热插拔，不必重启）；重新启用会再开一个。

## 三、用法

1. 导入（设置 → Copilot 插件 → 导入插件包，或拖 zip 进对话）→ **启用** →
   热加载引擎在运行进程内即时装载（含 `agent_tools.py` / 页面 / 托盘 / 快捷键），**无需重启**；
2. 打开 Copilot 浮层 →「代码地图」页签 → 「选择目录」→ 扫描（后台线程，界面不卡）；
3. 或者直接对 AI 说：「帮我看看 `C:\my\repo` 有多大，代码主要在哪」——它会调 `code_map`；
4. `Ctrl+Alt+W` 随时弹报告（用缓存，10 分钟内不重复扫描）。

## 四、统计口径（读结果前先看这里）

- **代码行数**只统计代码/文本类后缀（`.py/.ts/.js/.md/.json/...`），二进制与媒体跳过；
- 默认排除 `.git` / `node_modules` / `dist` / `build` / `__pycache__` / `.venv` 等依赖与产物目录；
- **符号链接不跟随**（防环、防越界）；
- 硬上限：2 万文件 / 深度 6 / 单文件读 2MB / 20 秒，超限自动截断并在结果里标注
  「已达上限截断（部分结果）」——大目录请调小 `depth` 或指定子目录再扫；
- `by_dir` 按**相对根目录的第一段**聚合，根目录下的散文件归到 `.`。

## 五、配置（config.json）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `refresh_minutes` | 10 | 缓存刷新间隔（分钟）；0 = 只在启动时预热一次 |
| `max_depth` | 4 | 服务预热时的扫描深度（1~6） |
| `exclude` | 空 | 额外排除的目录名，逗号分隔 |

服务模块按 `Path(__file__).parent.parent / "config.json"` 直接读这个文件
（Copilot 插件的配置不会自动注入环境变量，这是插件侧最省事的读法）。

## 六、回滚

停用插件即按备份整体回滚：新建的 `core/code_map.py` 删除、`core/agent_tools.py` 还原，
转译层不留残骸；热加载引擎即时卸载，页签/托盘/快捷键/工具在运行进程内立即消失。

> 注意：启用后 `core/agent_tools.py` 会被快照进转译层。如果你还在改这个文件的源码，
> 请先停用插件再改，否则源码改动会被转译层里的旧快照遮住。
