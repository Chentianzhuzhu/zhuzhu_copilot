# Piano Studio：让 AI 真正弹出声音

本插件把音符事件推送到局域网网页，由浏览器 Web Audio 实时合成音频。**你自己不会发声，也不会生成音频文件**；你负责用 MCP 工具指挥演奏，用户负责在网页里点一次「开始聆听」。

## 标准流程（按顺序）

1. 调 `piano_status` 取收听地址。若 HTTP 显示未启动，先调 `piano_server(action="start")`。
2. 把地址（优先局域网地址）告诉用户，请用户用手机或电脑打开，并点击页面上的「开始聆听」。
   - 用户没点之前，浏览器不允许自动播放声音；这是浏览器策略，不是插件故障。
   - 若你有 `preview_open` 工具，可直接在用户默认浏览器里打开该地址，再请用户点一下。
3. 需要换音色时先调 `piano_voices` 拿真实 id，**不要自己编造音色 id**。
4. 调 `piano_play` 演奏。一次调用会**打断**当前正在演奏的曲目；完整曲子请一次传入全部音符，不要连续快速调用。
5. 用户要停时调 `piano_stop`；想看进度或连接数再调 `piano_status`。

如果 `piano_play` 返回「还没有页面开启声音」，把地址再发给用户，等用户开启后重新调用一次即可。

## 记谱法

`notes` 是用空格或逗号分隔的音符串，每个音可带修饰：

| 写法 | 含义 |
| --- | --- |
| `C4` | 绝对音高（中央 C） |
| `C` | 不写八度时使用 `octave` 参数指定的音区 |
| `F#3` / `Bb4` / `Db5` | 升降号；也支持 `♯` `♭` |
| `60` | 直接写 MIDI 音高（A0=21，C8=108） |
| `C4+E4+G4` | 和弦（用 `+` 连接，同时发声） |
| `C4@500` | 这个音到**下一个音**的间隔为 500ms |
| `C4:420` | 这个音的发声长度为 420ms（不写则约为间隔的 88%） |
| `C4!0.7` | 这个音的力度 0.05-1.0（不写用 `velocity` 参数） |
| `R@400` 或 `-@400` | 休止 400ms（不发声，只推进时间） |

修饰可以组合，顺序为「音高 @间隔 :长度 !力度」，例如：

```
"C4@400 E4@400 G4@400 C5@800"
"C4+E4+G4@1200:1100!0.7"
"C4@300:280 D4@300:280 R@300 E4@600"
```

`notes` 也接受数组：字符串数组，或 `{"note":"C4","ms":400,"dur":320,"velocity":0.8}` 对象数组；`{"rest":500}` 表示休止。

## 音区（低 / 中 / 高）

`octave` 参数只影响**没写八度**的音符：

- `low` → 低音区（八度 3）
- `mid` → 中音区（八度 4，默认）
- `high` → 高音区（八度 5）
- 也可以传 `0`-`8` 的数字八度。

写了绝对八度的音符不受影响（`C5` 永远是 C5）。旋律跨越多个音区时，直接写绝对音高最稳妥，例如 `C3 G3 C4 E4 G4 C5`。

## 间隔与完整曲目

- `interval_ms` 是**默认每音间隔**（毫秒），单个音可用 `@ms` 覆盖，所以可以写出有长短变化的旋律。
- `duration_ms` 是**默认发声长度**；0 表示自动（间隔的 88%）。想要连奏就把它调大，想要断奏就调小。
- 一首完整的曲子建议一次调用传入全部音符，并用 `@ms` 控制每个音的长短；插件上限为 2048 个音、30 分钟。
- 如果曲子确实很长，分成几段调用时，必须等上一段演奏结束（`piano_status` 看进度）再调下一段，否则会打断上一段。
- `title` 会显示在收听页上，写曲名即可。

## 音色

调 `piano_voices` 获取全部音色 id 与说明。默认音色由插件配置决定（通常是 `grand_piano`）。常用：

- `grand_piano` 大钢琴 / `electric_piano` 电钢琴 / `music_box` 八音盒
- `organ` 管风琴 / `strings` 弦乐 / `nylon_guitar` 尼龙吉他
- `marimba` 马林巴 / `synth_lead` 合成主音 / `pad` 氛围铺底 / `celesta` 钢片琴

音色由 `web/voices.json` 数据驱动（泛音、包络、颤音、噪声），不是采样音频；不要承诺「和真实乐器一模一样」。

## 工具

| 工具 | 用途 |
| --- | --- |
| `piano_play` | 演奏：`notes` 必填；`octave` `voice` `interval_ms` `duration_ms` `velocity` `title` 可选 |
| `piano_stop` | 立即停止 |
| `piano_status` | 服务地址、浏览器连接数、当前曲目与进度 |
| `piano_voices` | 列出音色与音区说明 |
| `piano_server` | `start` / `stop` / `restart` / `status` 局域网 HTTP 服务，可传 `port` |

## 边界

- 演奏只由本机 MCP 触发；网页是**只读收听端**，不要试图用 POST 或网页按钮控制演奏。
- 用户没打开页面、没点「开始聆听」时，声音不会出现；如实说明，不要假装已经播放。
- 音符超出 A0-C8 会报错；按报错提示调整八度，不要反复重试同一个越界音符。
- 局域网收听需要设备在同一 Wi-Fi；首次启动若 Windows 防火墙弹窗，请让用户允许专用网络访问。
