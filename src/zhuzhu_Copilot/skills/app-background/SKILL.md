# app-background：自定义客户端背景与磨砂玻璃

当用户要求"换背景 / 自定义背景 / 设置壁纸 / 背景图片 / 磨砂玻璃 / 毛玻璃 / 玻璃质感 /
调整模糊 / 调透明度 / 让界面更通透 / 液态玻璃 / 界面太实了"时使用本技能。

## 0. 一次性把参数收齐（禁止挤牙膏式提问）

绝大多数情况下**不要**反复询问。按下面的默认组合直接落地，仅在用户明确要求时才追问：

| 用户意图 | 推荐组合 |
|---|---|
| 只说"换个背景" | 背景图 + `blur=24`、`frost=0.45`、`edge=0.55`、`opacity=0.35`、`liquid=0.25` |
| "通透一点 / 液态玻璃" | 背景图 + `blur=32`、`frost=0.22`、`opacity=0.22`、`edge=0.62`、`liquid=0.6` |
| "磨砂 / 看不清背景" | 背景图 + `blur=40`、`frost=0.72`、`opacity=0.5`、`edge=0.4`、`liquid=0.15` |
| "液体流动 / 活的" | 在任意组合上加 `liquid_anim=true`（有 CPU 代价，先告诉用户） |
| "不要背景，纯色就好" | `op=clear` + 按需调参数 |

用户若没给图片，**必须先用 ask_user 问一句**：要「用本地已有图片」，还是「让 AI 生成一张」。
其余细节（模糊多少）不要问，直接给推荐值再让用户微调——调整是即时的，试错成本很低。

## 1. 拿到背景图（三种来源，都可直接落到 op=set）

**A. 用户已有本地图片** → 直接 `set_app_background(op="set", image="<绝对路径>")`。
接受 png / jpg / jpeg / bmp / webp；其他格式明确告知不支持，不要尝试转换。

**B. 用户给的是图片网址** → `set_app_background(op="set", url="<http(s) 地址>")`，
工具会下载并收编（仅 http/https，超过 24MB 会拒绝）。

**C. 需要生成一张** → 两步走，**先生成再设置**：
1. 先按 `image-gen` 技能的正确姿势生成图片（真实 API 调用，等待时间给足），
   拿到本地文件路径；
2. 再 `set_app_background(op="set", image="<上一步的本地路径>")`。

生成提示词要点：背景图会被高斯模糊并以低透明度透出，所以**要低对比、大面积色块、
避免细密文字与高对比边缘**。直接说"给一个柔和渐变的抽象背景，深蓝到石墨黑"这类
描述比"一张照片"效果好得多。不要生成带水印、带 logo、带文字内容的图。

## 2. 五个维度怎么调（对应工具参数）

| 参数 | 范围 | 作用 | 调大的效果 |
|---|---|---|---|
| `blur` | 0–48 px | 背景图的高斯模糊半径 | 背景越朦胧，细节越不可辨 |
| `frost` | 0–1 | 磨砂底的不透明程度 | 玻璃越"毛"，背景越被遮住 |
| `edge` | 0–1 | 边缘受光描边与顶部反光强度 | 玻璃越有厚度、越"亮边" |
| `opacity` | 0–1 | 整层玻璃的不透明度 | 0 几乎全透，1 完全不透明 |
| `liquid` | 0–1 | 液光与底部呼吸的幅度 | 越像流动的液体 |

另有三个结构性字段：
- `fit`：`cover`（裁切铺满，默认）/ `contain` / `stretch` / `tile`
- `liquid_anim`：液态流动动效，**默认关闭**（持续重绘有 CPU 代价，用户要"活的"才开）
- `frameless`：无边框玻璃窗口外壳，**默认关闭**（会换掉系统标题栏）

## 3. 落地与迭代

先查现状，再改，再确认：

```
set_app_background(op="get")                                  # 看当前状态
set_app_background(op="set", image="C:/path/wall.png", blur=28, frost=0.4)
set_app_background(op="params", opacity=0.25, liquid=0.6)     # 只动参数，不换图
set_app_background(op="params", reset=true)                   # 回到默认外观
set_app_background(op="clear")                                # 清掉背景图，回到主题渐变
```

要点：
- **参数变化即时生效，不需要重启、不需要重建面板**，也不要把任务停下来等它生效。
- 一次 `op="set"` 可以同时带参数，别拆成两次调用。
- 图片会被**复制**进应用数据目录（`~/.zhuzhu_Copilot/agent/backgrounds/`），
  所以引用临时路径/下载目录也没问题，重启后不会丢。
- 调完把最终参数值**用文字回报给用户**（各维度当前取值），用户才知道现在是什么状态。

## 4. 边界与禁忌

- 这是**全局外观**，作用于整个客户端，不是某一个对话；改了就是全局改了。
- 不要把 `opacity` 调到接近 1 又同时把 `frost` 拉满——界面会变成一块不透明板子，
  背景图等于白设。这两者是互相制衡的，调之前先想清楚要"透"还是要"实"。
- `frameless=true` 会换掉系统标题栏。开启前**先告知用户**这可能影响窗口拖动/最大化
  的手感；用户没主动要求就不要开。
- 背景图与参数都是用户数据，**不要**替用户删除 `backgrounds` 目录下的文件。
