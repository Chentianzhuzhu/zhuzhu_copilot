## 1. 深度提示词

```
请为我制作一个《{名称}》Excel 工作簿，并确认：
1) 用途：数据录入/台账、统计分析、财务模型、报表看板、测算工具？
2) 数据：字段、数据量、时间范围、数据来源；是否需要公式自动计算？
3) 输出：是否需要图表、条件格式、汇总、打印或导出 PDF？
4) 口径：单位、币种、小数位、税率/比率等关键参数？
要求：原始数据、参数、计算、展示分区清晰；表头加底纹冻结；
公式可追溯、不硬编码计算结果；数字格式统一；关键指标用条件格式/图表突出。
```

**生成指令模板**（变量填全后调用 `create_xlsx`）：

```
角色：资深{财务/数据}建模专家。输出《{名称}》，用途{用途}，受众{受众}。
工作簿分区：① 参数/假设（集中、可改）② 原始数据（规范表头、一行一条记录）
③ 计算（公式引用参数，不写死结果）④ 汇总/看板（关键指标+图表）。
样式：表头深色底白字并冻结、边框、隔行底纹；数字用千分位/百分号/币种格式；
异常/达成用数据条/色阶/高亮；图表标题图例齐全。
```

## 2. 工作簿类型与工作表组织

- **台账/录入表**：规范字段表头、冻结首行、筛选；一行一条记录。
- **统计分析**：明细 sheet + 汇总 sheet（公式），图表在汇总页。
- **财务模型**：参数假设 → 明细测算 → 汇总；公式链清晰、可审计。
- **看板/报表**：关键 KPI + 图表 + 条件格式；一屏可读。
- 工作表命名清晰（“参数/明细/汇总/看板”），顺序按使用流程；无关空表删除。

## 3. 数据布局规范

- **首行即表头**，字段名唯一、不合并数据区单元格；一列一个字段、不混合类型。
- 原始数据保持“方形清单”（flat table），不要在数据区插空行/多层表头，
  汇总放单独区域/工作表。
- 标题可用 `wordart` 大标题行（合并居中），与数据区分开；单位、口径在表内注明。
- 默认**冻结首行、加筛选**；列宽可用 `column_widths` 显式指定，长文本换行。
- 避免在公式中间插硬编码常数；常数集中到“参数”区。

## 4. 公式与计算口径

- 用公式而非手算结果；引用参数区，便于改一处、算全表。单元格写以 `=` 开头的
  字符串即按公式存储（如 `=C2/B2`、跨表 `=AVERAGE(明细!D2:D5)`）。
- 比率/汇总：`=实际/目标`、`=SUM(...)`、`=MAX(...)` 等；注意绝对/相对引用（`$`）。
- 合计行用 `~sum` 标记：数据末行对应列写 `"~sum"`，生成真实 `SUM` 公式，首列写“合计”。
- 校验口径：合计=明细之和；达成率等交叉勾稽要自洽。
- 纯 Python（openpyxl）写入的公式**不带缓存值**，预览显示公式本身（不做错误重算）；
  用 Excel 打开即自动计算出结果。除零/空值用 `IFERROR` 兜底。

## 5. 数字格式 / 样式 / 边框

- 单元格值支持 `{v, format}` 携带数字格式：金额 `#,##0` / `¥#,##0.00`、
  比率 `0.0%`、日期 `yyyy-mm-dd`；保留前导零用文本格式。
- 表头：深色填充 + 白色加粗 + 居中；正文细灰边框；默认隔行浅底提升可读。
- 对齐：数字右对齐、文本左对齐、表头居中；字号层级固定（标题 14–16、正文 10–11）。
- 列宽/行高适配；统一字体，不滥用颜色。

## 6. 条件格式 / 图表 / 图标

- 通过 sheet 的 `format` 字段设置（列号为含表头在内的 **1-based 绝对列号**）：
  - `data_bars:[列]`：数据条看大小。
  - `color_scale:[列]`：红黄绿色阶看高低。
  - `highlight:{max:[列], min:[列]}`：高亮最大/最小值。
- **图表**用 sheet 的 `charts=[{type,title,labels,values}]`：趋势 line、对比
  column/bar、占比 pie；图表数据写到表尾空闲列、生成可在 Excel 点选编辑的原生图表，
  预览渲染为内联 SVG。
- 图标/符号（★ ● ▲ ✓）用于状态标识、风格统一；KPI 可用大号数字 + 条件色。随附
  `assets/icons/bars.png` 等可复用。

## 7. 读取与编辑已有 Excel

- **读取**：`read_xlsx(path)` 返回结构化 Markdown + meta（sheets / cells / formulas /
  cond_formats / charts / merged），用于理解原稿、定位要改的位置。
- **编辑**：`edit_xlsx(path, ops=[...])` 以操作数组改稿，常用 op：
  - `set_cell`：设置某 sheet 某单元格值（`{sheet, cell/row,col, value}`）。
  - `replace_text`：全局查找替换。
  - `add_sheet` / `delete_sheet` / `rename_sheet`：增删改工作表。
  - `apply_format`：追加数据条/色阶/高亮。
- 编辑返回 `{ok, failed, total}`，失败的 op 按提示修正重试；想保留原稿先复制一份。

## 8. 交付前自检清单

生成或编辑后，先 `read_xlsx` / `extract_text(path)` 核对，并在预览面板切换各表查看，
逐项确认：

- [ ] 表头规范、冻结/筛选生效、数据区无合并、无空行混杂
- [ ] 公式写入正确、合计勾稽一致（用 Excel 打开看计算值，无 `#REF/#DIV`）
- [ ] 数字格式（币种/百分号/千分位/日期）统一、小数位一致
- [ ] 条件格式/数据条/色阶/最大最小高亮正确触发
- [ ] 图表标题/图例/数据齐全、在预览中可见
- [ ] 边框/对齐/列宽/字体统一、长文本不溢出；多 sheet 顺序正确
