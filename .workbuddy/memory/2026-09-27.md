## 其它教训
- `agent_panel.py` 是 **CRLF** 行尾（`tokens.py` 等其它文件是 LF）。用裸 Python
  `open(..., "w", newline="\n")` 改写会把整个文件变成 LF，产生 2 万行级虚假 diff。
  改这个文件一律用 Edit/Write 工具；若必须用脚本，写完要 `\n → \r\n` 还原。
