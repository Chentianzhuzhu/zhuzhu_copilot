## 追加（同日第五轮）：「无法接入模型：'latin-1' codec can't encode characters in position 7-60」

- 根因：urllib 按 **latin-1** 编码 HTTP 请求头。接口地址/API Key 混入中文（或全角字符）时，
  `http.client.putheader` 直接抛 `UnicodeEncodeError`，文案与"接入失败"无关，用户无法自查
  （position 7 = "Bearer " 之后，即 Key 本身是中文）。
- 修法（`core/agent_llm.py`）：
  ① 新增 `header_unsafe_hint(field, value)` / `validate_header_fields(base_url, api_key)`：
     预检非 ASCII（ord>255）并给出「字段名 + 第几个字符起 + 片段」的人话提示；
  ② `test_provider_connection`（连通性测试）、`fetch_provider_models`（获取模型列表）先预检，
     直接返回明确失败信息且不发请求；
  ③ `LLMClient.__init__` 存 `_header_hint`，`_raise_if_bad_headers()` 在
     `_chat_stream_once` / `_chat_once` / `_responses_stream` 三处发送前抛出
     `AgentLLMError("配置错误：…")`；
  ④ `_fallback_eligible` 排除「配置错误」→ 不回退内置模型（回退会掩盖配置问题）。
- 新增 `tests/test_llm_header_guard.py`（8 项：预检、两处返回提示不联网、client 抛明确错误
  且不回退、responses 路径、ASCII Key 不被误拦、以及直接复现原始 latin-1 报错证明必要性）。
- 本机排查：用户持久化配置是**加密存储**且解密后 Key/地址均为 ASCII（合法），
  说明失败源于弹窗里输入的临时值（中文串）——修复后报错会直接点名字段与位置。

### 2. 修复：融入主窗口（dock）模式下最小化→恢复，左右子面板消失

- 根因：**dock 子面板是主面板的普通子控件**（随父窗口同隐同显，Qt 自动处理），但最小化分支与

  `show()`。注意 `isVisible()`/`isHidden()` 在 WindowStateChange 送达时**已被 Qt 置为非可见**，
  故「快照最小化前可见性」的做法无效（走过弯路，已废弃）。
- 修法：抽出 `AgentPanel._collapse_float_windows()` / `_collapse_ext_panels()`，**只收起 float
  独立窗口**；dock 面板不显式 hide（随之自动隐藏、随之自动回归）。`hideEvent` 同样复用。
- 验收：探针由「BUG 复现」→「未复现（面板均在）」；`scripts/_verify_panel_resize.py`、
