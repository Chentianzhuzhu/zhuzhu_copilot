## PPT 元素动画与切换增强（git 3f290d4）

需求：AI 生成 PPT 时加入创意性入场/退场动画与各种元素动画，并增强 skill 约束与示例文件。

### 关键实现
- python-pptx 无公开动画 API → pptx_builder 直接注入原生 `p:timing` XML（set 隐藏→animEffect→set 显示链，逐步骤 par 结构仿 PowerPoint 保存格式）。step 内多 spid 链式逐个播放形成卡片/图表"逐层浮现"。
- **默认开启动画**：每页按 标题→图形→正文 三层分组入场，效果随页序从创意池轮换（fade/wipe/box/circle/diamond/dissolve/plus/iris/checkerboard/randombar/reveal/appear），同组图形一步内链式出现。启发式分组跳过背景/装饰线/页脚（shape bbox + 文字判断）。
- 控制面：`style.animation=false` 整份关；`style.animation_effect` 全局统一；页级 `slide.anim={title/text/graphics:效果, exit:退场, enabled:false}`；封面仅动文字。
- 幻灯片切换改原生 `p:transition`（原占位 transition_type=0 无效）：支持 fade/push/wipe/split/cover/pull/zoom/dissolve/circle/diamond/blinds/checker/wheel/comb/plus/newsflash/cut/wedge/random，名称含中文别名。
- agent_tools schema 补齐 anim 页级对象 + transition 扩充说明；doc-gen SKILL §3.5 动画节奏规范（宁少勿滥、数据页链式、章节 push/zoom 等）；新增 `skills/doc-gen/references/animation-guide.md` 参数速查（agent 可 read_file 读取）。
- 结构陷阱记录：`p:prevCondLst/nextCondLst` 必须挂在 `p:seq`（cTn 兄弟）而非 cTn 内，否则 PowerPoint 时序非法。
