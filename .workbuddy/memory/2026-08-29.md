## zhuzhu Copilot：@子Agent 直接调用（commit d911dfe）

### 需求
支持 `@子Agent名 任务` 直接调用用户自定义子 Agent（subagents.json），不经主 Agent 转发。

### 实现（仅改 src/winapp_migrator/ui/agent_panel.py）
- `@` 候选列表与 tooltip 加入自定义子 Agent（`agent_subagent.registered_subagents`），显示 goal 摘要；
  `_cmd_desc` 同步支持。
- `_resolve_at_route` 匹配顺序：自定义 Agent（@agent 会话切换）> 自定义子 Agent（@子Agent 直接调用）
  > 工作流（@工作流 向后兼容）；未知名提示列出三类可用项。
- `_send` 识别 ("subagent", name) → `_launch_subagent`：
  - 复用当前会话工作流 + 受限工具白名单（无命令执行/无确认通道，agent_subagent 约束）；
  - 独立 LLMClient（按力度/服务商路由，与主引擎一致），后台线程跑 `run_sub_agent`；
  - 事件经 evt_signal 回主线程渲染 sub 块（title=子Agent·名，idx=0）。
- 停止支持：`_sub_stop` Event 传给 run_sub_agent 的 stop 回调；`_stop()` 识别子 Agent 运行态。
- 收尾：`_subagent_running()` 纳入 `_refresh_meta` 的 running 判断（防误收尾）；
  `_route` 分发 subagent_done → `_on_subagent_done`（清 _sub_stop、无输出补总结段）；
  `_show_end_badge` 子 Agent 分支（Successfully/Stop by user/Error）。
- 并发防护：主引擎线程/评估/其他子 Agent 运行中拒绝启动。
