# perf-turbo · 性能优化插件

界面交互与 Agent 输出两侧同时提速。**综合性源码级插件**：新建模块 + 替换既有代码 +
插入接线，另配一个实时看板与三档调速。

## 一、它到底改了什么

| # | op | 目标 | 作用 |
| --- | --- | --- | --- |
| 1 | `create_file` | `core/perf_turbo.py` | 性能内核：渲染缓存、节拍自适应、指标采集、报告诊断 |
| 2 | `replace_module` | `ui/agent_panel.py` | 把 `def _md_to_html(...)` 换成缓存包装，原实现改名 `_md_to_html_uncached` 保留 |
| 3 | `insert_after` | `ui/agent_panel.py` | 在 `delay = _STREAM_TICK_MS if ...` 之后追加节拍微调（异常保留原值） |
| 4 | `insert_after` | `core/agent_tools.py` | 在 `TOOLS = [` 后登记 `perf_report` 工具 |
| 5 | `insert_after` | `core/agent_tools.py` | 在 `revert_copilot_plugin` 分支后接线 `perf_report` 分发 |

外加 `copilot.json` 声明：后台服务（挂钩 + 界面心跳）、性能看板页、托盘动作、
`Ctrl+Alt+P` 快捷键。

## 二、两边各自怎么变快

**界面交互**

- 正文渲染结果按「文本 + 主题版本」做跨会话 LRU 缓存（默认 6MB）。
  切会话、回滚历史、切主题后重建富文本时，相同段落不再重复解析 Markdown。
  流式期间每段已有块级缓存，这一层补的是跨消息/跨会话那一层。
- 流式内容节拍按「档位 + 实测主线程响应间隔」微调：主线程 P95 > 80ms 时自动
  放大间隔保住输入与滚动，机器轻快时可切「激进」档让落字更密。
  应用自身算好的 delay 是基准，插件只在它基础上做小幅修正，绝不越过 2~60ms。

**Agent 输出**

- 量出真实瓶颈而不是猜：首字延迟（TTFT）、输出吞吐（字/秒）、输入体积、
  每个工具的 P95 耗时、整轮任务耗时。
- `perf_report` 工具让 Agent 自己看得到这些数（用户问「为什么这么慢」时直接回答，
  不必凭空解释），报告里带规则化建议：TTFT 高 → 输入体积/上游；某工具 P95 高 →
  换更轻的等价工具；帧延迟高 → 降低同屏渲染压力。

## 三（附）、玻璃窗口与热插拔

看板页用 `"window": "glass"` 托管在**独立无框液体玻璃窗口**里：应用启动即常驻浮现，
可拖拽标题区移动、贴边缩放，背景是真实桌面，玻璃折射/反射/边缘高光由 GPU 逐像素算
（见根 README 第八章 8.8）。只想在浮层里看就删掉 `copilot.json` 里该页面的
`"window": "glass"`，改回默认页签即可。

**停用插件会立刻关掉这个窗口**（热插拔，不必重启）；重新启用会再开一个。

## 三、怎么用

1. 导入：设置 → Copilot 插件 → 导入插件包，或把 zip 拖进对话输入框；
2. 启用：插件卡片的「启用」——会先过插件校验系统，再把变更写入转译层，
   热加载引擎在运行进程内即时装载（无需重启）；
3. 打开 Copilot 浮层 → 「性能看板」页签，或按 `Ctrl+Alt+P` 看完整报告。

三档调速（看板顶部，选择会持久化）：

| 档位 | 适用 | 行为 |
| --- | --- | --- |
| 激进 | 高配机、追求最顺滑落字 | 节拍压到 2ms 起，缓存 12MB |
| 均衡 | 默认 | 跟随应用默认值，按实测帧延迟自适应 |
| 保守 | 低配机、长文/多子 Agent 任务 | 节拍放宽到 8ms 起，缓存 3MB |

## 四、卸载与注意

- 停用插件即按备份整体回滚（新建的 `perf_turbo.py` 删除，两个被改文件还原），
  转译层不留残骸；
- **启用后 `ui/agent_panel.py` 与 `core/agent_tools.py` 会被快照进转译层**。
  如果你还在改这两个文件的源码，请先停用插件（回滚转译层）再改，否则源码改动会被
  转译层里的旧快照遮住——这是所有源码级插件共有的语义，不是本插件特例；
- 全部改动只碰这三个文件，不涉及校验系统、安全引擎、导入钩子与入口程序。
