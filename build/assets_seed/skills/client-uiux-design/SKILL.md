# 客户端 UI/UX 设计（大厂 AI 客户端质感 5 招）

本 Skill 把"大厂 AI 客户端质感"拆成 **5 条可执行细节**，任何一条单独拎出来都能明显去掉"廉价塑料味"。逐条遵守，界面就能从"机关枪乱晃的塑料感"变成"温润丝滑的艺术品"。

适用技术栈：PyQt6（QSS/QGraphicsEffect/QPropertyAnimation）、QML、Kotlin Compose、Flutter、SwiftUI、HTML/CSS/JS。示例以 PyQt6 为主，但原则是**跨框架通用的**，落到任何框架时翻译成对应写法即可。

## 第 1 招：不画边框，靠 1%~3% 微对比色阶分层

**问题**：新手最爱到处画线条、套大卡片、用刺眼的纯黑边框，界面显得生硬廉价。
**大厂做法**：全站背景每一层之间只差 **1%~3% 亮度**，靠整体氛围拉开层次，**绝不用纯黑色**。

### 落地规则
1. **禁止边框线**：默认不画 `border`。分层用"相邻层背景亮度差 1%~3%"实现，而不是描边。
2. **不用纯黑**：背景色不要用 `#000000`，用深灰蓝/暖灰（如 `#1a1b1e`、`#16171a`），靠色相带一点倾向。
3. 层与层之间：主背景 → 卡片 → 悬浮层，每层亮度差控制在 1%~3%（约 5~12 个 8bit 亮度值），营造"呼吸"感。
4. **输入框聚焦不用亮线**：聚焦时不用突兀的高亮描边，而是让它的**双环阴影整体加深**，做出"温润咬合"的凹陷/浮起感（双层 box-shadow，内环加深、外环扩散）。

### PyQt6 落地示例
```python
# 三层背景，亮度差约 2%，不画边框
MAIN_BG    = QColor("#1a1b1e")   # 主背景
CARD_BG    = QColor("#1d1e22")   # 卡片，比主背景亮 ~2%
FLOAT_BG   = QColor("#212228")   # 悬浮层，比卡片亮 ~2%

# 输入框聚焦：双层阴影加深（无边框、无亮线）
input_widget.setStyleSheet("""
    QLineEdit {
        background: #1d1e22;
        border: none;
        padding: 8px 12px;
        border-radius: 8px;
    }
    QLineEdit:focus {
        background: #212228;      /* 聚焦：仅加深背景，无亮线 */
        border: none;
    }
""")
