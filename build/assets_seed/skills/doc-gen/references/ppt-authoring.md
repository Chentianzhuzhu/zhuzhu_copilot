# PPT 生成 · 深度提示与设计规范

生成演示文稿前读本文件：先用「深度提示词」澄清任务，再按结构与设计规则产出，
最后 `read_pptx` / `extract_text` 校验、在预览面板放映自检。

## 1. 深度提示词（可直接套用）

信息不全时，把下面这段作为澄清提示（一次只问 2–4 个关键点，不要堆砌问题）：

```
请为我生成一份《{主题}》PPT，并先确认：
1) 受众与场景：给谁看（领导/客户/学员）、汇报还是路演/培训？
2) 目标：要对方做什么决策，或记住哪 3 个要点？
3) 篇幅与比例：约多少页、16:9 还是 4:3？
4) 素材：是否有数据/图表/品牌色/Logo/模板？
要求：封面+目录+正文+结尾；每页一个核心观点并写在标题；数据用图表、
对比用表格、流程用图示；统一配色与字体。
```

**生成指令模板**（变量填全后调用 `create_pptx`）：

```
角色：资深{行业}演示顾问。输出 16:9、约 {N} 页的《{主题}》。
受众：{受众}；核心目标：{目标}；必须传达的 3 个要点：{要点}。
结构：封面 / 目录 / {章节} / 总结与行动建议。
每页：① 观点式标题（结论先行，不写“概述”这类空标题）
     ② 支撑内容（数据/图表/图示/表格），文字精炼为短句
视觉：主色 {色值}，中性灰底，强调色仅用于关键数据；标题加粗、字体统一。
```

## 2. 标准结构（叙事骨架）

按场景选骨架：

- **工作汇报**：封面 → 目录 → 背景/目标 → 成果（数据）→ 问题与分析 →
  下步计划/资源需求 → 总结致谢。
- **商业路演**：痛点 → 解决方案/产品 → 市场规模 → 商业模式 → 竞争优势 →
  数据/里程碑 → 团队 → 融资/合作诉求。
- **培训教学**：导入 → 学习目标 → 知识讲解（分段）→ 案例/演示 → 练习 → 回顾。
- **技术分享**：背景问题 → 方案/架构 → 关键技术 → 实现/踩坑 → 效果数据 → 展望/Q&A。

目录页章节 3–5 个；正文每章节 1–3 页。主题类 PPT 一般 **12–25 页**，
**总页数 = 要点数 + 固定页（封面/目录/结尾）**，封面、目录、8+ 正文、结尾缺一不可。

## 3. 版式与一页一义

- **一页只讲一个观点**，把结论写进标题（“Q4 营收超额 22%”而非“营收情况”）。
- 保持对齐、统一边距与网格；不要每页换一种排版，相邻页交替使用
  要点 / 卡片 / 图表 / 表格 / 图示页，避免连续多页纯文字。
- 常用版式：封面、目录、章节分隔、标题+要点、标题+图表、标题+表格、
  标题+图示（流程/时间线/组织架构）、两栏对比（`two_col`）、大数字（`hero_stats`）、
  聚焦金句（`center_highlight`）、图文（`left_image`）。
- 文字量：正文每页 3–6 条、每条写成 15–40 字完整句子；能用图就不堆字。
- 安全区：元素距页边 ≥ 0.4 英寸，关键内容不靠最边缘。

## 4. 视觉与配色规则

- 先定 **1 主色 + 1 强调色 + 中性灰**；强调色只给关键数据/结论。
- `style.theme` 按内容气质选：business 商务 / tech 科技 / green 环保 / warm 文艺 /
  red 党政年节 / black-gold 高端 / dark 暗色；同时换一两个布局或封面参数，
  **严禁全部默认同一商务蓝**。
- 背景与正文对比度足够；挑 3–5 页用 `bg_color` 浅色/深色，不要全篇白底。
- 除非任务明确要求，**避免大面积靛蓝/紫色**。
- 字体统一：标题一种（加粗）、正文一种；中文默认微软雅黑，避免渲染成方块。
- 字号层级固定（标题 28–32、副标题 20、正文 14–18、注释 10–12）。

## 5. 图表 / 表格 / 图标

- **比较大小/趋势**用柱状/折线图；**占比**用饼图/环形（类别 ≤ 5）；
  **多维评价**用雷达图；**流程/时间/组织**用 `diagram` 而非文字。
- 图表必须有标题、坐标轴单位、图例；数值标签清晰；颜色与主色一致。
- 精确数值/多维对比用**表格**：表头加底纹、数字右对齐、千分位/百分号格式统一。
- 图标用于引导视线与分类，风格统一（线性或填充一致）。可复用随附图标
  `assets/icons/`（star / bars / target / check），不要混用多套风格。
- 需要真实配图（封面/开篇/收尾）用 `generate_image` 生成与主题一致、留白足够的素材，
  再以 slide 的 `image` 字段插入。

## 6. 动画与切换（克制）

- **默认已开启创意动画**，按 标题→图形→正文 分层逐元素播放；目录页/致谢页用
  `anim=false` 关闭。切换统一（内容页 fade/wipe，章节开篇 push/zoom），不要花哨 3D。
- 演讲型 PPT 宁少勿滥；全自动放映可 `style.animation=false` 或各页全用 appear。
- 效果名、触发方式、级联与退场的完整字段见 `references/animation-guide.md`，
  禁止凭空猜测字段。

## 7. 读取与编辑已有 PPT

- **读取**：`read_pptx(path)` 返回结构化 Markdown + meta（slides / charts / tables /
  anims / shapes / 页面尺寸），用于理解原稿、定位要改的位置。
- **编辑**：`edit_pptx(path, ops=[...])` 以操作数组改稿，常用 op：
  - `replace_text`：全局查找替换（改标题/术语/数字）。
  - `set_title` / `add_bullet`：改某页标题、追加要点。
  - `replace_image` / `remove_slide` / `move_slide`：换图、删页、调序。
- 编辑返回 `{ok, failed, total}`，**失败的 op 要按提示修正后重试**；想保留原稿先复制一份。

## 8. 交付前自检清单

生成或编辑后，先 `read_pptx` / `extract_text(path)` 核对，并在预览面板点「从头放映」
走一遍，逐项确认：

- [ ] 标题均为观点式、无“概述/简介”空标题；每页都有 title
- [ ] 结构完整：封面、目录、8+ 正文、结尾，无空页/残页
- [ ] 文字无溢出/截断；图表有图例/单位、不缺系列
- [ ] 表格表头底纹、数字格式统一、无错位
- [ ] 全篇配色/字体/对齐统一；中文正常显示（非方块）
- [ ] 切换/动画如预期（放映时逐条出现）；页码/页脚一致
