本页结构几乎全部由 admin.js 渲染，脚本未执行时就会显示为空白。

最常见原因是浏览器或 CDN 缓存了旧版本资源：请按 Ctrl+Shift+R 强制刷新；若仍无效，请确认 /admin/admin.js 能否正常打开。
