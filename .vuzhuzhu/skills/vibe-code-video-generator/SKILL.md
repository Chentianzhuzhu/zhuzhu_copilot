# Vibe代码视频生成规范（Vibe Motion 程序化MG动画）
核心目标：输出可直接渲染导出MP4的动画代码，优先两种技术栈：
1. p5.js Canvas（轻量、适合粒子/球体/流体几何动效，和截图同款神经球）
2. Remotion（React+TS，强时间轴控制，字幕、配音、动画精准对齐，适合带旁白长文案）

## 一、输入拆解规则
收到用户需求，先提取4要素：
1. 旁白文案：逐句口播文本，自动拆分字幕时间点
2. 画面风格：暗调紫粉发光、科技神经、柔和流动、低饱和辉光（默认抖音科普Vibe风格）
3. 主视觉元素：粒子球面、连线网络、扩散波纹、缓慢旋转、拖影光晕
4. 时长&分辨率：默认 1080×1080，24fps；默认每段文案 3~4s

> 默认模板风格（用户不指定就用这个）：深色暗夜背景，紫色/洋红柔光粒子，缓慢自转神经球体，线条淡辉光，低速度、舒缓不晃眼，文字居中柔和渐显，和截图"想他，是大脑在喊饿"视频视觉保持一致。

## 二、两个技术栈选型判断
- 用户想要【快速预览、粒子几何、神经球、简单科普短片】→ 输出 **p5.js 单HTML文件**
  ✅ 特点：浏览器直接打开预览；用p5.capture / puppeteer 抓帧，FFmpeg合成mp4
- 用户想要【长文案、严格字幕配音对齐、精准时间轴、商用成片】→ 输出 **Remotion TSX代码**
  ✅ 特点：remotion render 一键导出视频，字幕卡点精确，支持单独配音轨

## 三、画面强制设计约束（对齐Vibe抖音质感）
1. 背景：深色暗色，不要纯黑 `#090814` 这类深紫黑，带极慢全局暗场流动噪点
2. 动效速度：所有旋转、粒子运动**低速舒缓**，旋转角速度很小，避免高速晃动刺眼
3. 发光：用半透明叠加实现辉光，不使用刺眼饱和高光；线条透明度 40~80，节点中心亮、外围衰减
4. 文字：遵循之前 `client-uiux-design` UI规范：
   - 暗色模式字重降一档；文字渐显是水墨晕染（透明度0→1，60~120ms）
   - 文字不跳动，固定居中；一句字幕全程停留到旁白读完，自动切换
5. 配色默认Vibe科普套：
   - 粒子：#e880ff 淡紫粉；中心光点：#ffdd99暖黄；连线：rgba(200,90,230,0.6)
6. 禁止：硬边框、尖锐闪烁、剧烈抖动、高饱和刺眼颜色

## 四、代码输出标准
### p5.js 输出格式
输出完整独立HTML，内置p5 cdn，用户直接浏览器打开就能预览：
- setup()：初始化球面点位、画布尺寸
- draw()：每一帧旋转、画线、绘制发光节点、字幕渲染
- 内置时间控制器：`frameCount` 控制字幕切换时机
- 末尾附带【导出视频命令】：p5.capture用法 + FFmpeg合并帧脚本

### Remotion 输出格式
- 完整TSX组件，定义duration、fps、composition尺寸
- 按旁白分句拆分Sequence，每个字幕和动画时间绑定
- 使用remotion内置Opacity动画实现水墨渐显
- 末尾附带渲染命令：`npx remotion render`
